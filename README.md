# Internetmarke Studio

**Weniger Handarbeit beim Briefversand – kostenlose Windows-App, öffentliche Beta 0.20.0.**

- JTL-CSV automatisch einlesen und optional kaufen/drucken.
- Marken-Shop ohne CSV: Warenkorb, Mengen und Einschreiben.
- Druckerassistent, Kalibrierung, Logo und Absenderadresse.
- Guthaben im Blick, Archivsuche und Nachdruck ohne neuen Kauf.
- Hintergrundbetrieb, optionale Löschfristen, Sicherung und Updates.

[**Windows-Installer herunterladen**](https://github.com/JD-KODE/internetmarke-studio-downloads/releases/latest) · [Einrichtung Schritt für Schritt](INSTALLATION.md) · [Alle Funktionen und Bedienung](BETA-ANLEITUNG.md)

Software kostenlos, Porto kostenpflichtig. Ein freigeschalteter Post-API-Zugang ist erforderlich. Kein separates Python nötig. Unabhängiges Projekt, kein offizielles Produkt von JTL oder Deutsche Post. Öffentliche Beta, Nutzung auf eigenes Risiko; gesetzliche Ansprüche bleiben unberührt.

## Neu in 0.20.0
Geführte Druckereinrichtung mit Vorlagen und Kalibrierung; mehrzeilige Absenderadresse; automatischer Status „Druck übergeben“; aktivierte Löschfristen starten automatisch, Löschdaten im Archiv. Eine Druckübergabe bestätigt keinen tatsächlichen Papierausdruck. 30 Tage Aufbewahrung empfohlen.

200 Windows-Tests und Installations-/Startprüfung bestanden. Hardware-Ausdrucke bitte selbst testen. Installer noch unsigniert; die Beschriftung „Private Testversion“ im geprüften Paket stammt aus der Testphase.

Dieses Repository enthält öffentliche Downloads und Dokumentation. Der Quellcode bleibt privat.
